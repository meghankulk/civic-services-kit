# Civic Services Kit

An unofficial study of civic-services product design: a component library, a knowledge-graph ontology (D3, 2D and 3D), and a product builder that turns a service description into click-through flows.

Live: https://meghankulk.github.io/civic-services-kit/

Not affiliated with or endorsed by Kaizen Labs or any agency. Built from public pages for interview prep.

The builder's open "design from any prompt" mode needs Claude and runs only inside claude.ai; on this site it builds the closest preset instead.

`./sync.sh` refreshes this copy from the source folder.
